# Start here

This is an **overlay ZIP**, not a complete copy of the original academy repo. Copy only the `dashboard-tutor/` folder into the root of the repository you cloned from GitHub. Follow `dashboard-tutor/README.md` to install, scan, inject, serve, record, and publish.

`test-fixtures/fixture.html` is a minimal demonstration dashboard used to validate the detection and mock action plan; it is not part of the academy.

The original GitHub repo was **read through the GitHub connector**, but the container cannot clone external repos and this environment's Chromium has a URL-blocking policy. No source page has been overwritten here or pushed to GitHub. Test the overlay on your Windows development machine before publishing.
