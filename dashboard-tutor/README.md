# Tinitiate AI Universal Dashboard Tutor — MVP

Reusable overlay for [Tinitiate MasterClass Academy](https://github.com/venkata-bcs/masterclass-interactive-web-training-center). **No changes have been pushed to GitHub.** The archive contains the new `dashboard-tutor/` directory plus documentation and a standalone smoke-test fixture.

## What it does now

- Scans repository HTML to identify candidate interactive dashboards; writes a registry to `dashboard-tutor/manifests/registry.json`.
- Injects **one shared** tutorial loader into detected HTML pages (idempotent `install`; no content/logic replacement).
- Shows a **16:9 empty video placeholder above the dashboard** and an authoring **Record Tutorial** button. After a successful recording, it embeds the generated MP4.
- The local recording service opens an isolated 1920x1080 Chromium browser, hides page header/footer for recording, focuses the active dashboard, animates a visible pointer, clicks/edits safe controls, and draws synchronized explanation subtitles.
- Automatically reads live DOM controls (including many dynamically rendered ones), then selects an adapter-based action plan. Python Print has a dedicated 11-scene walkthrough: progress, Start Learning, editor, Run, output, edit, Run again, Reset, Next, slide list.
- Requests scene narration from ElevenLabs using your voice ID and API key; combines timed audio with actual browser capture using FFmpeg. A `--silent` mode exists **only for pipeline tests**, and will produce a video without narration.
- Produces `assets/dashboard-tutorials/<dashboard-id>.mp4` and corresponding `.json` metadata, which static hosting can serve after publication.

## Installation on Windows PowerShell

1. Clone **your actual repository** on your own machine. Copy `dashboard-tutor/` from this ZIP into the root next to `foundational/` and `pyspark/`.
2. Run:

```powershell
cd C:\Code\masterclass-interactive-web-training-center\dashboard-tutor
npm install
npx playwright install chromium
ffmpeg -version
```

3. In the same PowerShell session, configure your ElevenLabs credentials **without putting them in HTML**:

```powershell
$env:ELEVENLABS_API_KEY = "YOUR_PRIVATE_API_KEY"
$env:ELEVENLABS_VOICE_ID = "YOUR_VOICE_ID"
# Optional: open a visible fullscreen automation window on your desktop
$env:TUTOR_VISIBLE = "1"
```

4. Discover and inject the shared viewer (these commands are intentionally separate so you can review the inventory before editing many pages):

```powershell
node cli.js scan
# Review dashboard-tutor/manifests/registry.json and the detected pages
node cli.js install
node cli.js serve
```

5. Open <http://127.0.0.1:4173/foundational/python/print.html>. A video placeholder and **Record Tutorial** button appear above the dashboard. Click Record. A local browser performs the guided demonstration, and the finished MP4 becomes available above the dashboard.

> Note: On Windows, leave the serving terminal open while generating. The recording takes place in a separate isolated browser session. On Windows the recorder defaults to a visible fullscreen-style Chromium window. Use `TUTOR_VISIBLE=0` for headless capture, or `TUTOR_VISIBLE=1` to force a visible window on other platforms; recording still uses a 1920x1080 viewport, and exports a 1920x1080 MP4.

### Headless smoke test without consuming ElevenLabs credits

In a **second** terminal while the authoring server is running, stop/restart it with `$env:TUTOR_SILENT='1'` then:

```powershell
cd C:\Code\masterclass-interactive-web-training-center
node dashboard-tutor/cli.js record foundational/python/print.html --silent --limit 3
```

This records a silent **test clip**, not a finished voiced tutorial. Remove `TUTOR_SILENT` and repeat a normal Record to create the narrated final.

## How reusability works

- `lib/scanner.js`: repository inspection and injection.
- `lib/live.js`: rendered DOM detection for controls generated by JavaScript/React.
- `lib/plan.js`: reusable control/action narration templates and the Python Course adapter.
- `lib/stage.js`: fullscreen-style single-screen focusing, cursor animation, readable subtitles.
- `lib/recorder.js`: actual Playwright actions, timing, video capture and FFmpeg composition.
- `lib/server.js`: localhost-only authoring API, job status and static MP4 delivery.
- `client/tour.js` and `.css`: one shared widget used on every supported page.

The pipeline does **not** assume that every HTML page is a dashboard. It scores interactive candidates and records only detected candidates. It does not auto-push files or auto-run ElevenLabs on every GitHub commit.

## Supported vs. still needs hardening

**Working code paths implemented:** repository scanner, page injector, video placeholder, REST recording API, live control discovery, PyCourse and generic simulator lesson plans, cursor overlay, ElevenLabs request and aligned FFmpeg mix. JS syntax, scanner/plan tests, and synthetic FFmpeg media pipeline can be tested without browser access.

**Not yet verified end-to-end on the actual GitHub repository:** browser rendering, per-page fit and readability, React rerendering during interactions, click semantics for every custom visualization, Pyodide execution, actual ElevenLabs requests, and publishing to hosted GitHub. A generic fallback covers simple button dashboards but does **not** guarantee that every bespoke dashboard's control is understood. The repository must be tested locally, and adapters extended for outliers.

**One-screen rule:** the recorder uses a fixed 1920x1080 canvas with document scrolling disabled and scales large stages only within a readability limit. Very large dashboards may require scene-specific stage layouts; those should be flagged rather than blindly shrunk to unreadable text. The normal learner page layout is not forcibly flattened.

**Security:** recording is available only through the local service bound to `127.0.0.1`. Do not expose this authoring server to the public internet or commit `.env` / credentials. On static deployments, existing MP4s still play but the Record control requires the local authoring service.

**Performance:** ElevenLabs narration is generated before capture, one clip per scene. Clips are paid API calls; review scripts and test in silent mode first. Existing lesson localStorage is isolated in a fresh browser context during recording.
